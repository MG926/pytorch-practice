Python 虚拟环境操作指南（Windows CMD）
=========================


【创建虚拟环境】
-----------------------------------------------------------

1. 进入项目目录：
   cd /d "F:\pytorch practice"

2. 创建虚拟环境：
   python -m venv 环境名

   本项目示例：
   python -m venv .venv

3. 在 CMD 中激活：
   call "环境名\Scripts\activate.bat"

   本项目示例：
   call ".venv\Scripts\activate.bat"

   也可使用绝对路径激活，无需先进入项目目录：
   call "F:\pytorch practice\.venv\Scripts\activate.bat"

4. 激活后，CMD 提示符前会出现环境名：
   (.venv) F:\pytorch practice>

5. 退出虚拟环境：
   deactivate


【删除虚拟环境】
-----------------------------------------------------------

1. 先退出虚拟环境（若已激活）：
   deactivate

2. 确认当前目录和待删除的环境名无误后，删除虚拟环境文件夹：
   rmdir /s /q "环境名"

   本项目示例：
   rmdir /s /q ".venv"


【导出/还原依赖】
-----------------------------------------------------------

1. 导出已安装的包到文件：
   python -m pip freeze > requirements.txt

2. 从文件安装依赖：
   python -m pip install -r requirements.txt


【清华镜像源】
-----------------------------------------------------------

1. 临时使用清华源安装包：
   python -m pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple

2. 永久设为默认源（推荐）：
   python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

3. 验证是否配置成功：
   python -m pip config list

4. 换回官方源：
   python -m pip config unset global.index-url

5. 也可写入 Windows 配置文件 %APPDATA%\pip\pip.ini：
   [global]
   index-url = https://pypi.tuna.tsinghua.edu.cn/simple

6. 其他国内镜像源备选：
   阿里云   https://mirrors.aliyun.com/pypi/simple
   中科大   https://pypi.mirrors.ustc.edu.cn/simple
   豆瓣     https://pypi.douban.com/simple
